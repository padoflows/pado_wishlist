# 위시리스트 틀

물건 사진과 설명을 자유롭게 배치하고, 구매 완료한 항목을 체크해 PNG로 저장하는 위시리스트 틀 편집기입니다.

## 사용 방법

1. 물건 사진은 **배경을 지운 PNG**로 준비합니다. (remove.bg 같은 배경 제거 사이트를 이용하세요.)
2. 왼쪽 패널에서 제목과 각 항목의 설명을 입력하고 사진을 올립니다.
3. 미리보기에서 사진과 글 묶음을 끌어 옮깁니다.
   - 사진 모서리: 비율을 유지한 채 크기 조절
   - 변 가운데 손잡이: 가로나 세로만 조절
   - 위쪽 동그라미: 회전 (Shift를 누르면 15°씩)
   - 다른 요소와 줄이 맞으면 분홍 안내선이 나타나며 붙습니다. (Alt를 누른 채 끌면 잠시 끔)
4. 체크 상자를 누르면 구매 완료(■)로 바뀝니다.
5. **PNG 저장**으로 2400 × 1350(또는 4800 × 2700) 이미지를 저장합니다.
6. 이어서 작업하려면 **작업 파일 저장**으로 .json 파일을 받아 두세요.

물건 항목은 추가하거나 삭제할 수 있고, 4번 캐릭터 항목에는 사진 칸이 없습니다.
